# 📷 Zach Lucas Photography Portfolio

An absolutely stunning one-page photography display website with custom color controls and saveable presets.

## 🎨 Features

### ✨ Stunning Visual Design
- **Elegant Typography**: Uses Cormorant Garamond and Instrument Sans for sophisticated typography
- **Film Grain Overlay**: Subtle animated film grain for authentic photography feel
- **Minimalist Aesthetic**: Clean, sophisticated design that puts photos first
- **Smooth Animations**: Hardware-accelerated animations throughout

### 🎨 Custom Color System
- **Three Color Controls**: Background, Accent, and Highlight colors
- **Real-time Preview**: Instant visual feedback as you adjust colors
- **Hex Code Input**: Manual color entry for precise control
- **CSS Variables**: Dynamic theme system using CSS custom properties

### 💾 Saveable Presets
- **Built-in Themes**: 5 professionally designed presets (Forest, Monochrome, Warmth, Midnight, Sepia)
- **Custom Presets**: Create and save your own color combinations
- **LocalStorage**: Presets persist between sessions
- **Preset Management**: Easy creation and deletion of custom presets

### 🖼️ Stunning Gallery
- **Dynamic Loading**: Automatically loads all photos from the photos directory
- **Varied Layouts**: Mix of square, wide, tall, and large formats for visual interest
- **Lazy Loading**: Optimized performance with lazy-loaded images
- **Staggered Animations**: Gallery items fade in sequentially for elegant reveal
- **Hover Effects**: Subtle zoom and caption reveal on hover

### 🔍 Full-screen Lightbox
- **Keyboard Navigation**: Arrow keys and ESC for easy browsing
- **Smooth Transitions**: Fade animations between images
- **Image Counter**: Shows current position in gallery
- **Responsive**: Adapts to any screen size

### 📱 Responsive Design
- **Mobile First**: Optimized for all devices
- **Adaptive Grid**: Gallery layout changes based on screen size
- **Touch Friendly**: Large tap targets for mobile users
- **Performance Optimized**: Fast loading on all devices

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No server required - works with static file hosting

### Installation
1. Clone this repository or download the files
2. Place your photos in the `photos/` directory
3. Open `index.html` in your browser

### Usage
1. **Browse Gallery**: Scroll through the stunning photo collection
2. **View Photos**: Click any image to open full-screen lightbox
3. **Navigate**: Use arrows, keyboard, or swipe to browse photos
4. **Customize Colors**: Click the color palette icon (top right)
5. **Change Theme**: Select from built-in presets or create your own
6. **Save Presets**: Create and save custom color combinations

## 🎯 Customization

### Adding Photos
Simply add JPEG or PNG files to the `photos/` directory. The gallery will automatically load them.

### Color Presets
The system includes 5 built-in presets:
- **Forest**: Dark green with warm accents
- **Monochrome**: Classic black and white
- **Warmth**: Rich brown tones
- **Midnight**: Deep blue aesthetic
- **Sepia**: Vintage photography feel

### Creating Custom Presets
1. Adjust colors using the color pickers or hex inputs
2. Enter a name in the "Preset name" field
3. Click "Save" to store your preset
4. Your preset will appear in the list and persist between sessions
